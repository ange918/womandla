Site WOMANDLA (Next.js, App Router). La refonte reprend la palette et la structure des maquettes, avec les textes déjà présents dans le repo.

Variables d’environnement : copier `.env.example`. Sans Supabase, les formulaires répondent mais n’enregistrent rien côté serveur. Sans clé FedaPay, Kkiapay ou Stripe, le parcours de don crée une intention et ne débite pas.

```bash
npm run dev
npm run lint
npm run build
```

Migration : `supabase/migrations/20261007120000_candidatures_et_dons.sql`.
Stubs de paiement et de suivi : `supabase/functions/`.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
